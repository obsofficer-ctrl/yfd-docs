## Overview

Setting up YFD Docs locally allows you to preview your changes before submitting them for review. You will need to:

1. [Fork the repository](#step-1-fork-the-repository)
2. [Clone the repository](#step-2-clone-the-repository) to your local machine
3. [Create a branch](#step-3-create-a-branch) for your changes
4. [Build and run](#step-4-build-and-run-yfd-docs) YFD Docs locally

---

## Step 1: Fork the Repository

Forking creates your own copy of the YFD Docs repository on GitHub, which allows you to make changes without affecting the original repository.

1. Go to the [YFD Docs repository](https://github.com/Y-Foundry-Dao/yfd-docs) on GitHub
2. Click the **Fork** button in the top-right corner of the page

![Fork Repository on GitHub](../../assets/images/contribute/github-fork.png)

3. Select your GitHub account as the destination for the fork
4. Wait for GitHub to create your fork — you will be redirected to your forked repository

![Forked Repository](../../assets/images/contribute/github-forked.png)

---

## Step 2: Clone the Repository

Cloning downloads a copy of the repository to your local machine.

### Using GitHub Desktop *(Recommended)*

1. Open **GitHub Desktop**
2. Click **File** → **Clone Repository...**

![GitHub Desktop Clone Menu](../../assets/images/contribute/github-desktop-clone-menu.png)

3. Select the **GitHub.com** tab and find your forked `yfd-docs` repository

![GitHub Desktop Clone Dialog](../../assets/images/contribute/github-desktop-clone-dialog.png)

4. Choose a local path where you want to save the repository
5. Click **Clone**

![GitHub Desktop Cloning](../../assets/images/contribute/github-desktop-cloning.png)

GitHub Desktop will download the repository to your local machine.
