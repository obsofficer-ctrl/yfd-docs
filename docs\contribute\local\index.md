# Contribute Locally

Contributing to YFD Docs locally allows you to preview your changes before submitting them for review.

## Getting Started

Follow these steps in order to set up your local environment:

| Step | Page | Description |
|---|---|---|
| 1 | [Prerequisites](overview.md) | Install Git/GitHub Desktop and Docker |
| 2 | [Setup YFD Docs](setup-yfd-wiki.md) | Fork, clone, and run YFD Docs locally |

> **New to GitHub?** Learn about [branches](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/about-branches) before getting started.
