# Prerequisites
{: .no_toc }

Before you can contribute to YFD Docs locally, you will need to set up your environment with the required tools. This page will guide you through the prerequisites needed before [Setting Up YFD Docs](setup-yfd-wiki.md).

## Overview

Contributing to YFD Docs requires a few tools to be installed on your computer. Once you have these tools installed, you will be able to clone the YFD Docs repository and run it locally on your computer.

**Required Tools:**
- [Git](#git) or [GitHub Desktop](#github-desktop-recommended) *(recommended for beginners)*
- [Docker Desktop](#docker)

---

## GitHub Desktop *(Recommended)*

GitHub Desktop is the easiest way to get started contributing to YFD Docs. It provides a graphical interface for managing your local copy of the repository, creating branches, and submitting pull requests without needing to use the command line.

> **New to branches?** Learn about [branches in GitHub](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/about-branches) before getting started.

### Install GitHub Desktop

1. Download [GitHub Desktop](https://desktop.github.com/)
2. Install GitHub Desktop on your computer
3. Open GitHub Desktop and sign in with your GitHub account

![GitHub Desktop Sign In](../../assets/images/contribute/github-desktop-signin.png)

### Sign In to GitHub Desktop

1. Open GitHub Desktop
2. Click **Sign in to GitHub.com**
3. Follow the prompts to authorize GitHub Desktop

![GitHub Desktop Authorization](../../assets/images/contribute/github-desktop-auth.png)

## Git

If you prefer to use the command line, you can install Git directly.

### Install Git

1. Download [Git](https://git-scm.com/downloads) for your operating system
2. Follow the installation instructions for your OS:
   - **Windows**: Run the installer and follow the prompts
   - **macOS**: Install via [Homebrew](https://brew.sh/) with `brew install git` or download the installer
   - **Linux**: Use your package manager, e.g., `sudo apt-get install git`
